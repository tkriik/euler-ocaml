* If asked about a Project Euler problem, do **not** give a straight-up solution, but only hints and tips on what to think about. Examples:
  - a mention about a mathematical formula
  - algorithms to look into
  - a thought exercise
  - et cetera
* Project Euler problems can be found in `problems.txt`, and the corresponding code in `p{n}.ml` (or `p{n}{version}.ml`, in case of alternative solutions to the original). For example, the code for problem 14 is in `p14.ml`, and its alternatives are in `p14b.ml`, `p14c.ml`, et cetera.
* Refer to `ocaml.txt` for an OCaml 5.5 manual if needed
